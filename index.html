yolo-onnx-web

浏览器 ONNX 示例

YOLO 检测与 SAM 3 交互分割，均由 onnxruntime-web 在浏览器中运行。

Detection YOLO 分类、检测、分割、姿态、旋转框。GitHub Pages 自带示例模型。 Segmentation SAM 3 文本概念分割（PCS）与点/框视觉分割（PVS）。请自备导出的 ONNX 目录，不托管数 GB 权重。

English: browser ONNX demos for YOLO detection and SAM 3 interactive segmentation. SAM 3 does not ship the multi-GB weights; choose a local export directory on the demo page.
